NumPy: reshape y append

Lección 14, módulo 3. Cada punto indica lo que dice la plataforma, la corrección y una prueba que puedes ejecutar en Colab.

1. np.append no es una ufunc

Plataforma: «Join different arrays using the universal function np.append()».

Una ufunc aplica una operación elemento a elemento, como np.add o np.sin. np.append solo pega un array detrás de otro.

Corrección: «...using the NumPy function np.append()».
a = np.array([1, 2, 3]); b = np.array([10, 20, 30])
np.add(a, b)      # [11 22 33]
np.append(a, b)   # [1 2 3 10 20 30]
isinstance(np.add, np.ufunc)     # True
isinstance(np.append, np.ufunc)  # False

2. La regla de reshape: el producto

Plataforma: «the new shapes are proportional to the original ones».

La documentación dice que la nueva forma debe ser compatible con la original. En la práctica: el producto de las dimensiones nuevas debe ser igual al número de elementos.

Corrección: «the new shape must contain exactly the same number of elements as the original».
a = np.arange(20)
a.reshape((4, 5))    # 4×5 = 20 → funciona
a.reshape((-1, 5))   # NumPy deduce 4
a.reshape((-1, 6))   # ValueError: 20 no es divisible entre 6

3. reshape no modifica el original

Plataforma: «Modify the dimensions and internal structure of an array using .reshape()».

reshape devuelve una vista si es posible, y si no, una copia. El array original conserva su forma. Los datos no cambian, solo su agrupación.

Corrección: «Obtain a new shape for an array (without changing its data) using .reshape()».
a = np.arange(20)
b = a.reshape((4, 5))
a.shape   # (20,)  → el original no cambió
b[0, 0] = 99
a[0]      # 99 → comparten datos (vista)

4. Comodín -1: lo calcula NumPy y solo hay uno

Plataforma: «...so Python automatically calculates the missing dimensions».

Lo calcula NumPy, y solo se permite una dimensión desconocida por llamada.

Corrección: «...so NumPy automatically calculates the missing dimension (only one -1 is allowed)».
a.reshape((-1, 5))    # (4, 5)
a.reshape((4, -1))    # (4, 5)
a.reshape((-1, -1))   # ValueError: only one unknown dimension

5. append devuelve un array nuevo

Plataforma: «append copies the result into a new variable».

np.append no actúa in situ: crea un array nuevo. Tú decides si lo guardas en una variable. Y sin axis, aplana los arrays.

Corrección: «append returns a new array (a copy), so assign it to keep it».
a = np.array([1, 2, 3])
np.append(a, 4)       # muestra [1 2 3 4]
a                     # sigue [1 2 3]
a = np.append(a, 4)   # ahora sí: [1 2 3 4]

m = np.array([[1, 2], [3, 4]])
np.append(m, [[5, 6]])            # [1 2 3 4 5 6]  (aplanado)
np.append(m, [[5, 6]], axis=0)    # [[1 2],[3 4],[5 6]]

Autopreguntas

Piensa la respuesta y despliega.

¿Qué es una ufunc?
Una función que opera elemento a elemento sobre arrays, como np.add o np.sin.
¿Es np.append una ufunc? ¿Cómo lo compruebas?
No. Con isinstance(np.append, np.ufunc), que da False.
¿Qué condición debe cumplir la nueva forma en reshape?
El producto de sus dimensiones debe ser igual al número de elementos.
¿Por qué (-1, 6) falla con 20 elementos?
Porque 20 no es divisible entre 6. Lanza ValueError.
¿Modifica reshape el array original?
No. Devuelve una vista si es posible, o una copia. Hay que asignarlo para conservarlo.
¿Cuántos -1 admite reshape y quién calcula el valor?
Solo uno por llamada, y lo calcula NumPy.
¿Qué ocurre si usas np.append sin axis?
Aplana ambos arrays y devuelve uno 1D.
Ejecutas np.append(a, 4) sin asignar. ¿Cambia a?
No. Devuelve un array nuevo y a queda igual.
